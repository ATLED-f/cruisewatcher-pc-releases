# StarDream PC 發布

作者：Eric。

此倉庫只提供 Windows 免安裝分享套件、更新摘要與檔案校驗資訊，不提供原始碼，不包含會員帳號、密碼、登入資料或查詢紀錄。

## 下載

請前往 [Releases](https://github.com/ATLED-f/cruisewatcher-pc-releases/releases/latest) 下載分享套件，解壓縮後執行 EXE。需要 Google Chrome，會員自行登入並完成驗證。

目前自動更新功能尚未推出，請關閉舊版後再使用新版，並先保留自己的會員資料資料夾。
