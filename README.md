# StarDream PC 發布

作者：Eric。

此倉庫只提供 Windows 免安裝分享套件、更新摘要與檔案校驗資訊，不提供本程式原始碼，不包含會員帳密、登入資料或查詢紀錄。

## 下載

請前往 [Releases](https://github.com/ATLED-f/cruisewatcher-pc-releases/releases/latest) 下載分享套件，完整解壓縮後執行 EXE。需要 Google Chrome，會員自行登入並完成驗證。

## v0.8.50 · 更新第一階段

- 啟動時每天最多背景檢查新版一次，設定 → 檢查更新 可手動重試。
- 有新版時查看摘要，再自行下載並核對 SHA-256。
- 校驗成功後可開啟下載資料夾，由使用者手動解壓縮、關閉舊版並開啟新版。

不會自動安裝、覆蓋、關閉或執行程式。更新時請保留自己的 CruiseWatcherData 會員資料。首次使用此功能須先手動下載 v0.8.50 或更新版本。

SHA-256 僅用於完整性核對，本階段尚未加入獨立發布簽章。房況以官網為準，程式不會代按最終預訂或付款。
