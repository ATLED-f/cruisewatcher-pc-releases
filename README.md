# StarDream PC 發布

作者：Eric。此倉庫只提供 Windows 免安裝分享套件、更新摘要與校驗資訊，不含原始碼、會員帳密、登入資料或查詢紀錄。

## 下載

前往 [Releases](https://github.com/ATLED-f/cruisewatcher-pc-releases/releases/latest) 下載，完整解壓縮後執行 EXE。需要 Google Chrome，會員自行登入並完成驗證。

## v0.8.52 · 更新操作改善

- 更新視窗以主畫面置中，維持文字大小與精簡介面。
- 完成更新後底部短暫顯示版本，同一次只提示一次。
- 已下載套件重新核對大小與 SHA-256，有效即可沿用；無效時重新下載。

## 一鍵更新

- 設定 → 檢查更新，查看摘要後按「更新並重新啟動」。
- 下載與 SHA-256 校驗成功後切換新版，保留會員資料與設定。
- 新版啟動確認失敗會自動回復；成功更新後也可手動「回復上一版」。
- 查詢、登入或訂房協助期間只允許下載，結束操作後再切換。

請保留自己的 CruiseWatcherData 與其中 updates 資料夾。原 EXE 入口會轉開目前版本。更新後需重新確認登入，瀏覽器資料保留。啟動確認表示視窗可用，無法保證所有功能皆正常；斷電或檔案權限故障可能仍需手動開啟原 EXE。

v0.8.50 僅支援下載，首次請手動解壓並開啟 v0.8.52，之後支援一鍵更新。不會在背景無聲套用。SHA-256 為完整性校驗，尚未加入獨立發布簽章。程式不會代按最終預訂或付款。
